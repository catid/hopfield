# Exact expected-cost guard

At a current candidate set S, let positive integer weights w(c) be proportional to the unchanged source posterior, and let m be the number of remaining MAP steps before the baseline's depth-four posterior tree. The counterfactual baseline evaluator follows the fixed baseline for every c in S, using supplied candidate predictions rather than the actual case's future answers. Its complete vector b(c) is the exact remaining baseline call count. If t(c) is the current feasible tree's leaf depth, the guard compares the integers sum(w(c)t(c)) and sum(w(c)b(c)). No floating-point normalization is needed.

If the guard accepts, the tree's prescribed-posterior expected remaining cost is at most the baseline's. If it rejects, the policy takes the same next MAP query as the baseline and applies the same rule recursively. By backward induction on the remaining MAP budget, each subsequent branch has expected cost at most its fixed-baseline branch. At zero remaining MAP steps, both policies use the same posterior-optimal tree, so the guard is an equality. Singletons have zero remaining cost. An infeasible early tree leaves the MAP decision unchanged. Consequently the guarded rule has no larger expected cost under the prescribed posterior, conditional on exact baseline simulation, correct query predictions and valid optimality certificates.

Accuracy equality follows from the restriction argument: a depth-four tree identifying S also identifies every later baseline subset after impossible branches and constant queries are removed. Every counterfactual baseline branch from a feasible early set must therefore end exactly; a failure of that property is a correctness error and makes the study incomplete.

These are conditional optimization and identification properties. They do not imply a realized 2% reduction on an examined finite cohort, and they do not establish a population effect size or posterior calibration outside the declared sampling model.
