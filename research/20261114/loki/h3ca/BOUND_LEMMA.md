# Exact recomputed Huffman bounds, ordering, ties and depth reuse

For positive integer model weights, a separating binary decision tree induces a binary prefix code. Huffman's repeated two-smallest merges minimize weighted external path length over unrestricted binary prefix trees. Its exact merge sum lower-bounds every separating tree using the supplied catalog and any remaining-depth restriction.

To prove the bound, take two sibling leaves at maximum depth in a full binary prefix tree and place the two smallest weights there. Exchanging a smaller weight downward with a larger one cannot increase weighted path length. Merge those two leaves into one weighted by their sum. The remaining problem has one fewer leaf, and the difference in objective is exactly the merged sum. Induction proves the repeated two-smallest procedure optimal. Equal-weight coding-tree ties do not affect the lower bound or the separate scientific board tie rule.

For a proposed partition S=A union B, every tree has weighted cost at least mass(S)+H(A)+H(B). Options are explored by increasing (exact bound, board index), with child-information-bound-infeasible options last by board. The incumbent updates by (cost, board), since a later explored option can have an earlier board. Prune only if the bound strictly exceeds the incumbent, or equals it and has a later board. Equality with an earlier board must still be explored. No branch prunes before a feasible incumbent exists.

H3bw computes every Huffman bound from scratch at every actual ordering evaluation. It has no persistent Huffman subset cache: the proof's `huffman_bounds` registry is empty, and each ordering attempt contains both complete inline merge certificates. Every executed merge charges the work counter, including repeated computations of the same subset. Each trace records its mask, model count, exact cost and every two-smallest merge. Independent replay reconstructs the trace using a sorted list and bisect, verifies all weights/masks, and rejects any nonempty persistent bound registry. The inline receipts are retained scientific output records; no lookup structure reuses them to accelerate later bound evaluations. Tree memo states and counterfactual memo nodes still charge states.

This removes stored bound memo entries by doing more arithmetic, rather than renaming an existing cache. Singleton cost is zero and a pair costs their sum; both follow the same from-scratch path. All output serialization and memory use remain charged to CPU/wall budgets. The policy's value, option order, prune decisions, lexicographic optimum and chosen candidate paths are unchanged from the fully memoized compiler.

Normalize state depth to min(depth, subset_size-1), because a nonconstant query removes at least one other model along each candidate path. Preserve requested root depth in the input, proof header and cache identity. Equal effective root depths may reuse a previously completed canonical tree computation with identical candidates, weights and catalog. The source proof is read and hash-checked, its complete body is retained with only the requested-depth header changed, and the source group/proof/result identities are bound. This tree-level reuse is distinct from the removed subset-bound cache. It charges no nonexistent repeated computation but still charges hash checks and complete serialization to CPU/wall time. Independent replay compares the entire proof body and requested-depth limits.

Complete proofs are serialized before RAM caches retain only chosen routing states, weights, costs and leaf depths. No on-disk certificate is replaced by that compact routing cache. All materialized tree/counterfactual memo entries, actual recomputed merges and partition attempts are counted.
