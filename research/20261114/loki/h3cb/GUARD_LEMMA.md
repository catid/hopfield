# Budget-matched trees with conservative baseline admissibility

At a current set S after m paid MAP queries, the proposed tree has requested depth 8-m. The fixed baseline has 4-m remaining MAP queries followed by its original depth-four posterior tree. Counterfactual evaluation retains both predicted-label branches and every candidate. A terminal infeasible baseline tree adds zero membership queries and sets exact=False for every candidate at that terminal; this is expected inadmissibility, not technical failure or a dropped branch.

Handoff is eligible only when every candidate's original-baseline continuation identifies exactly. For such an eligible S, the complete counterfactual baseline policy is itself a separating binary tree with depth at most (4-m)+4=8-m. Its queries belong to the same full board catalog and its integer posterior weights are the current weights conditioned by noiseless labels. The new optimal tree's expected cost is therefore no greater than that baseline's. The explicit integer guard must pass whenever all baseline branches identify. A pure cost rejection in this regime is a correctness error, not an experimental finding. At m=4 the two requested depths are four and the guard must tie exactly.

If some baseline branch fails, the new rule rejects handoff regardless of any apparent numerical saving. It continues the unchanged next MAP query while fewer than four have been used. This all-branch criterion does not inspect the true candidate or exclude any experimental case.

An accepted tree identifies every candidate in S, and admissibility proves that the original baseline also identifies every candidate in S. Thus an early handoff preserves the actual case's exact flag. Without an early handoff, the MAP prefix is unchanged; at four MAP queries, depth four is the original terminal compiler, with equality when feasible and unchanged failure otherwise. Candidate counts above sixteen are ineligible for the new compiler and continue MAP unchanged. At the four-MAP endpoint a set larger than sixteen cannot be depth-four separated by the binary information bound. Every case therefore retains its original exact flag.

By backward induction, an accepted handoff has no larger prescribed-posterior expected cost, and rejection followed by the same MAP query retains that nonincrease through subsequent guarded decisions. This conditional property is separate from the finite-cohort primary requiring at least 2% realized total-call reduction. The maximum actual query count remains eight per case. No population effect size, independent confirmation, or calibration beyond the declared source model follows.
