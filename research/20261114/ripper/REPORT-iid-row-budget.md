Doubling rows also doubles deployment labels and pair coqueries, so this result does not identify a unique causal mechanism or establish universal noise robustness. An algebraic observation motivated using more data instead of a common affine score correction. For exact common edge costs `c′ = a c + b`, with `a > 0`, every degree-`d` feasible graph satisfies `Σx = 81d/2`; hence the optimal value is `F′(d) = aF(d) + b81d/2`. Exact second differences scale by `a`, preserving optimum faces, curvature maxima and lower-degree ties. Symmetric independent corruption maps clean equality probability `r` to `c + (1−9c)r`, where `c = p/4−9p²/64`. At ideal `p=1/20`, `c=311/25600` and the positive scale is `22801/25600`. The generator uses the archived float threshold 0.05. Finite smoothing, rounding, exposure-dependent corrections and numerical solver tie choices need separate treatment; no empirical noise-correction claim follows from this identity.
