This planning note has been superseded by the parent agent's frozen [H4d protocol](../foureyes/budget.json): the primary endpoint is the all-six-seed joint solve fraction at 4,194,304 moves, with a 16,777,216-move secondary tail endpoint. Root owns that execution. The operational continuation guidance below remains applicable; the original draft endpoint below is retained only as planning history.

Test whether mean accuracy across the six k10 search seeds reaches at least **99% at 16,777,216 moves per chain**, with zero wrong stops, on the same fixed `full-all[30000,40000)` cohort. Prespecify checkpoints at powers of two from 262,144 through 16,777,216 moves per chain. Keep four chains, the same random seeds, temperatures, focus, annealing period, stopping tolerance, compaction, and periodic refresh.

Continue each saved H1h normalized search state at 262,144 moves. The initial runner saves both `final_state.pt` and `capture_state.pt`, because the upstream `state_dict()` omits the instrumentation's best/certificate boards. Restore the generator, active puzzle mapping, per-chain fields, stop arrays, best energies, elapsed counters, and capture arrays. Change only `T_cap` and its derived bookkeeping cap. Never restart the search or regenerate its random initialization.

Before the long runs, validate state restoration and one check of continued search against an uninterrupted reference on a small existing development cohort. Require exact state and returned-board equality, including capture arrays. Save a resume receipt with model, dataset, source, checkpoint and environment hashes. If the extension moves to a different machine, record that boundary; the accuracy study follows the saved trajectories, while hardware timings cover only the measured continuation on that machine.

Run each seed once through all checkpoints. At each checkpoint, save the selected returned boards, solved and stopped masks, first stop moves, active puzzle count and cumulative issued chain moves. Independently validate every returned board's rows, columns, boxes and clues. Save resumable state after each checkpoint for recovery. If all puzzles stop before the maximum cap, end computation and carry their final outcomes forward to remaining checkpoints.

The primary endpoint is the six-seed mean at the fixed maximum cap; report per-seed values, paired uncertainty over seeds and shared puzzle indices, wrong stops and budget failures. A strict uncertainty rule can be frozen as: supported if the approximate 95% interval lower bound is at least 99%; falsified at this cap if its upper bound is below 99%; otherwise inconclusive. Also report the first *prespecified* checkpoint reaching the empirical 99% target. Do not stop the study simply because an intermediate estimate crosses 99%.

All recovered graphs are identical up to a global coupling scale. Six source fits therefore do not provide six independent recovered structures; remaining variation is mostly search seed and floating-point arithmetic. This is a computational-budget result on the same corpus cohort, not an external generalization test or an equal-budget improvement over unextended controls.

Six independent continuations can occupy four available GPUs, with the last two queued dynamically. The expected bottleneck is the unsolved tail, so record active puzzles and achieved moves per second rather than interpreting utilization alone. Do not duplicate the 262,144-move prefix or launch redundant per-budget runs. A geometric sequence of caps gives useful early measurements while retaining an explicit maximum budget.
