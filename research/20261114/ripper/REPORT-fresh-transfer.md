# H1bh: fresh recipients fail both fixed transfer targets

Both prespecified finite targets are **falsified**. Aligned fixed donor feedback recovers **28/32 certified integral exact graphs**, below the required 29. Permuted feedback recovers **25/32**, so the aligned-minus-permuted difference is **+3**, below the separate required +4. Every proof resolves: the procedure bound is exactly 28 and the contrast bound exactly +3. The earlier 30/32 versus 26/32 result on examined recipients is not pooled into these decisions.

The protocol pinned the **2,016,891-ID declared Ripper completion-source ledger** and all historical donor hashes before sampling. It drew 32 independent 900-row banks without replacement within a bank from the remaining 1,815,103 official training identities. There are **28,580 new unique IDs**, 28,800 bank-row instances, and **220 repeated instances across banks**. There is no within-bank repeat, declared-ledger overlap, or donor/recipient overlap. The updated Ripper source ledger contains **2,045,471 unique IDs**. These sources are disjoint from the declared Ripper ledger only; they are not claimed untouched by every repository experiment or drawn from an external distribution.

Ordering was enforced for the full study: first seal all selected source IDs, then generate and save **all 64 recipient mask streams**, and only then materialize selected CSV labels. Source and donor audits precede any LP fit. The independent source auditor rebuilds the 21-manifest historical exclusion union, reproduces every new source draw, verifies every selected CSV answer and Sudoku constraint, and reconstructs every donor snapshot from its actual archived first 300 queried rows. The fresh source, noise, tie, and cell-permutation seed families were fixed before outcomes.

Each recipient index uses the same fixed donor matrix as H1bf. The aligned arm retains its coordinates; the control uses a newly seeded cell permutation. Both matrices remain immutable and have identical full off-diagonal value histograms. The acquisition policy uses `(8/9)^recipient_coquery_count / (1 + fixed_feedback)` with no recipient-label feedback. Actual recovery counts still include all 900 rows. New mask-independent whole-board corruption is shared by the paired arms: draw U and a uniform 81-position permutation, and permute the board iff U < 9/160. The algorithm receives no noise probability.

Independent audit reproduces all 57,600 recipient masks and all queried values/counts. Each of 64 complete-label substitution gates changes every source value and every queried value while preserving every mask and coquery count; final equality counts change. Thus the negative result is not explained by an unresolved provenance check or accidental recipient-label feedback. It is the retained outcome of the frozen procedure on the sealed recipients.

All **64 exact integer primal-dual proofs** pass. Recovery still uses all 3,240 pairs, exact half-even rounded Laplace equality-rate costs, and degree exactly 20 at every cell. Degree and implied 810-edge cardinality remain supplied priors; geometry is used only for evaluation. No primal is snapped. The two certified fractional control optima are resolved failures and do not exclude integral co-optima; proof validity does not establish uniqueness.

This fresh-recipient result limits the earlier finite success claims: the unchanged static-transfer recipe did not reproduce either target here. It does not show zero alignment benefit—the observed difference remains +3—or prove that transfer is impossible. Historical donor label information and shared indexed topology remain part of the procedure. No cutoff, donor, permutation, or recipient bank was retuned or replaced after the failures, and no population probability or unique causal mediator is inferred.
