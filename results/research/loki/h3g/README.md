# H3g: complete-pattern holdout

Frozen 512-pattern primary result: **supported**. Every valid completion of every one of the 8,192 evaluation inputs lies outside the largest 512-pattern training bank. Compatible-bank retrieval cannot answer any input.

This is a conditioned bank-incompatible distribution (0 one-clue, 16 two-clue, 8,176 three-clue inputs), not the original GRAM distribution. The 32/128 banks are secondary nested controls.
