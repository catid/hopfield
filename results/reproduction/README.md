# Original reproduction snapshot

The original CRAM reproduction completed on 2026-11-14 within the [confirmed scope](../../configs/study_scope.json): main results, controls and ablations, with published baseline comparisons. See [the result report](../../REPRODUCTION.md).

This directory publishes compact evidence copied without altering its contents. [The export manifest](export-manifest.json) records the original local path, public destination and SHA-256 digest of each file. Large model weights, datasets, per-puzzle arrays and logs remain outside Git.

[The final audit](final_reproduction_audit.json) is a dated snapshot of the original reproduction, including 1,431 file identities. Its document hashes refer to the documents at completion time. The repository README and public documentation were subsequently reorganized, and ongoing research is separate. The old [README snapshot](README-snapshot.md) is retained verbatim for history; its relative links describe the original workspace and are not a navigation guide for this public directory.

Use the current [rerun guide](../../docs/RERUN_GUIDE.md) and [paper coverage map](../../docs/PAPER_COVERAGE.md) to navigate the study. Paths beginning `artifacts/`, `upstream/`, `dataeff_source/` or `objective_source/` in old receipts identify local archived evidence and are not downloads included in this checkout.
